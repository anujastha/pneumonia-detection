## How to Run

1. Clone the repository:
```bash
git clone https://github.com/yourusername/pneumonia-detection.git
cd pneumonia-detection
```

2. Install the required dependencies:
```bash
pip install -r requirements.txt
```

3. Launch the notebook:
```bash
jupyter notebook miniprojectpnemonia.ipynb
```

## Dataset

Please ensure you have the dataset used in this project. If it’s not included for licensing reasons, download it from the [Kaggle Chest X-Ray Dataset](https://www.kaggle.com/paultimothymooney/chest-xray-pneumonia) and place it in the appropriate folder.
